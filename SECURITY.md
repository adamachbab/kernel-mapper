# Security

## Scope and risks

This repository contains kernel-level research code. Incorrect behavior can crash Windows, corrupt memory or cause data loss. It is not a hardened production component and has no published supported-version matrix.

Use only in an isolated laboratory on systems you own or are explicitly authorized to test. Do not experiment on production systems or machines containing valuable data.

## Reporting

Report vulnerabilities privately to the maintainer through a verified private contact channel. If GitHub private vulnerability reporting is enabled, use the repository's Security page. Otherwise, request a private contact method without posting technical exploit details publicly.

Include the affected revision, a concise description, expected impact and relevant environment details. Remove credentials, personal information, signing material and sensitive system data from attachments.

## Limitations

A successful build does not establish runtime safety. Source organization, documentation and screenshots do not constitute a security audit or endorsement of the project's behavior.
